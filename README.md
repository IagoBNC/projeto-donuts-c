# DONUTS em C

Projeto desenvolvido para a disciplina **Introdução à Programação Computacional (MC0004)** da **Universidade Federal do Cariri (UFCA)**.

O objetivo do projeto é implementar o jogo de tabuleiro **DONUTS (antigo INSERT)** utilizando a linguagem C, seguindo as especificações fornecidas pelo professor.

## 🎯 Objetivo

Desenvolver uma implementação completa do jogo DONUTS utilizando conceitos fundamentais da linguagem C, incluindo:

- Modularização do código;
- Estruturas (`struct`);
- Matrizes;
- Ponteiros;
- Manipulação de arquivos de cabeçalho (`.h`);
- Organização em múltiplos arquivos (`.c` e `.h`);
- Validação de entradas;
- Lógica de jogo.

## 🚀 Como executar

### Utilizando o CLion

1. Abra o projeto no CLion.
2. Aguarde o CMake configurar o projeto.
3. Clique em **Run**.

### Utilizando GCC

```bash
gcc *.c -o donuts
./donuts
```
